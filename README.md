# FlyChat Android

Este proyecto empaqueta el prototipo HTML original de FlyChat dentro de una aplicación Android mediante WebView.

## Generar APK
1. Abre esta carpeta en Android Studio.
2. Espera a que Gradle termine de sincronizar.
3. Ejecuta Build > Build APK(s).
4. El APK de depuración quedará en:
   app/build/outputs/apk/debug/app-debug.apk

## Nota
El proyecto conserva el prototipo original. Chats, respuestas y varias funciones siguen siendo demostraciones; convertirlas en funciones online reales requiere backend, autenticación, base de datos, almacenamiento, notificaciones y servicios de llamadas/IA.
